O que é o SIGS e como usar

O SIGS é uma plataforma integrada de gestão industrial desenvolvida para a Stoll. Ele cobre o ciclo completo da operação — da previsão de demanda ao registro de produção no chão de fábrica — e é dividido em seis módulos que devem ser usados em sequência. Cada módulo alimenta o próximo.

Dica de navegação

A barra "Fluxo do Sistema" no Dashboard principal mostra quais etapas já têm dados carregados (✓) e quais estão pendentes (○). Use-a como ponto de partida toda vez que abrir o sistema.

1

Configuração

Uma vez · Manutenção trimestral

É a etapa que você faz uma vez e atualiza quando o portfólio ou a estrutura de produção mudam. Acesse pelo menu CONFIGURAÇÃO → Base de Dados.

MóduloO que configurarImpacto
Base de Dados Cadastrar SKUs ativos (código, descrição, segmento) Referência para todos os cruzamentos do sistema
Processos Definir etapas produtivas (costura, corte, acabamento…) Usado pelo TOC para calcular gargalo e pelo MES para apontamento
Matriz de Set Up Tempo de troca entre produtos em cada processo Usado pelo Preactor para sequenciar minimizando setup
Calendário Dias úteis, turnos, horas por turno Base de capacidade para TOC e Preactor
Atenção

Se o Calendário e a Matriz de Set Up não estiverem preenchidos, os cálculos de capacidade do TOC e do Preactor ficarão estimados com valores padrão, podendo gerar planos irreais.

2

Importação de dados

Mensal · CSV ou XLS

Aqui você carrega os dados do ERP ou das planilhas para dentro do sistema. Acesse pelo menu IMPORTAÇÃO. O formato aceito é CSV ou XLS.

MóduloO que importarColunas mínimas esperadas
Vendas Histórico mensal por SKU Código · Descrição · colunas por mês (jan/24, fev/24…)
Estoque Posição atual de estoque Código · Quantidade · Valor (opcional para R$)
Ordens de Produção OPs abertas ou planejadas Nº OP · Código · Quantidade · Status · Emissão
Cliente Faturamento por cliente Cliente · Valor Total
Costura Dados de eficiência de costura Código · Segmento · dados de eficiência

Como importar (passo a passo)

1. Acesse o módulo desejado no menu IMPORTAÇÃO.
2. Clique em Importar e selecione o arquivo CSV ou XLS.
3. O sistema exibe as colunas detectadas — confirme qual coluna representa o código, a quantidade, etc.
4. Clique em Salvar. Os dados ficam armazenados e disponíveis para todos os módulos.

Atenção ao mapeamento de colunas

Errar o mapeamento (por exemplo, mapear a coluna errada como "código") gera distorções em todos os módulos. Revise com cuidado na primeira importação de cada arquivo.

Dado sensível — Cliente R$ 16M

O arquivo de cliente contém 12.908 linhas com R$ 16M+ de faturamento. Nunca exclua esses dados sem necessidade — reimportar é simples, mas perder o histórico prejudica análises comparativas.

Backup antes de reimportar

Antes de substituir qualquer importação, use o botão ⬇ Backup no topo do Dashboard para salvar todos os dados em JSON.

3

S&OP — Planejamento de demanda e estoques

Mensal

Aqui você transforma os dados históricos em decisões de produção. Acesse pelo menu S&OP. É composto por quatro telas que devem ser usadas nesta ordem.

3.1 · Previsão de Demanda

Gera a estimativa de vendas futuras por SKU com base no histórico. Requer a importação de Vendas.

MétodoQuando usarIndicador de qualidade
Média Móvel Demanda estável, sem tendência ou sazonalidade MAPE
Erro Médio Absoluto
Percentual por SKU

< 15% → excelente
15–30% → aceitável
> 30% → revisar
Holt-Winters Demanda sazonal (verão/inverno, coleções, datas comemorativas)
Regressão Linear Produto em crescimento ou queda constante
Boa prática

Se o MAPE de um produto estiver acima de 30%, revise o método ou considere tratar esse SKU manualmente. Produtos com comportamento muito irregular respondem melhor ao Holt-Winters.

3.2 · Política de Estoques

Classifica cada SKU e define quanto manter em estoque para cada nível de serviço. Requer a Previsão de Demanda rodada.

ParâmetroO que significaValor típico Stoll
Lead Time Tempo de reposição (meses). Inclui produção + aprovação. 1 a 3 meses
Nível de Serviço Tolerância a ruptura. 95% → Z = 1.65 · 90% → Z = 1.28 90% padrão · 95% para produtos A
Horizonte histórico Quantos meses de vendas usar para calcular variabilidade 12 meses
ABC automático Aplica nível de serviço diferente por classe (A = 95%, B = 90%, C = 80%) Recomendado ativar

Os parâmetros são salvos automaticamente — na próxima abertura da tela já estarão preenchidos.

Após calcular, o sistema classifica cada SKU em quatro status:

StatusSituaçãoAção imediata
RUPTURA Estoque abaixo do estoque de segurança. Risco real de falta. Produzir com prioridade máxima
RISCO Estoque abaixo do ponto de reposição ideal. Programar produção no próximo ciclo
OK Dentro da política definida. Monitorar normalmente
EXCESSO Mais de 2× o ideal em estoque. Capital parado. Não produzir. Girar via promoções ou renegociação.
Impacto financeiro

Quando o arquivo de estoque tiver o campo de valor, o sistema calcula automaticamente a receita em risco (RUPTURA + RISCO) e o capital parado em excesso. Esses valores aparecem no Dashboard principal para decisão imediata.

3.3 · Plano de Produção

Consolida a previsão de demanda com o estoque atual e gera uma sugestão de quanto produzir de cada SKU no próximo período. É a entrada natural para a criação das OPs no ERP.

O plano mostra: demanda prevista · estoque atual · estoque de segurança · quantidade sugerida a produzir. Exporte para XLS para usar como base de emissão de OPs.

3.4 · Dashboard S&OP

Visão executiva com evolução de previsão versus realizado e snapshots de rodadas anteriores para comparação histórica. Use em reuniões mensais de S&OP.

4

TOC — Identificação do gargalo

Mensal ou quando a mix muda

A Teoria das Restrições (TOC) identifica qual processo produtivo está limitando a capacidade total da fábrica. Acesse pelo menu TOC → Gargalo (TOC).

Como usar

1. Selecione o ano de análise.
2. O sistema cruza a demanda prevista com a capacidade disponível de cada processo (Calendário + processos cadastrados).
3. O processo com maior percentual de utilização é o gargalo.

UtilizaçãoSituaçãoDecisão
> 100% Gargalo real — capacidade esgotada Horas extras · subcontratação · corte de mix
85–100% Zona de risco — qualquer variação causa atraso Monitorar semanalmente. Preparar contingência.
< 85% Processo com folga disponível Pode absorver demanda adicional sem risco

Fila do gargalo

A fila mostra quais OPs estão aguardando o processo gargalo. Use-a para priorizar: produza primeiro as OPs de maior valor ou com prazo mais crítico.

Alerta automático

Se o gargalo ultrapassar 100% de utilização, um alerta vermelho aparece automaticamente no Dashboard principal com o nome do processo e o percentual.

5

PREACTOR — Sequenciamento da produção

Mensal ou semanal

Organiza as OPs em uma sequência de execução visual — o Gantt — considerando a capacidade de cada processo. Acesse pelo menu PREACTOR → Linha do Tempo.

Como usar

1. Selecione o mês a sequenciar.
2. O sistema posiciona as OPs no tempo conforme a capacidade disponível de cada processo.
3. Barras em vermelho indicam conflito de capacidade (sobreposição).
4. Reordene as OPs conforme prioridades comerciais (prazo, cliente VIP, valor do pedido).

Regra prática

Respeite sempre a sequência do gargalo (definida no TOC). Os demais processos devem ser agendados subordinados ao gargalo — nunca produza na frente do gargalo o que ele ainda não tem capacidade de processar.

6

MES — Execução no chão de fábrica

Diário · Tempo real

O MES (Manufacturing Execution System) registra o que acontece de verdade na produção, em tempo real. Acesse pelo menu MES → Chão de Fábrica.

6.1 · Aba Apontamento — como registrar a produção

PassoAçãoDetalhe
1 Selecionar OP pendente Na lista de OPs importadas, clique na OP desejada. O formulário é preenchido automaticamente.
2 Completar informações Selecione o processo, operador e máquina. Confirme a quantidade planejada.
3 Iniciar apontamento Clique em Iniciar Apontamento. O cronômetro começa automaticamente.
4 Registrar parada (se houver) Clique em Registrar Parada, escolha o tipo, selecione um motivo rápido (chips) ou escreva um motivo específico.
5 Retomar Quando o problema for resolvido, clique em Retomar. O cronômetro volta a correr.
6 Finalizar Informe a quantidade produzida e o refugo. Clique em Finalizar.

Tipos de parada

TipoQuando usarImpacto no OEE
Não planejada Quebra inesperada, falha de equipamento Reduz Disponibilidade (D)
Planejada Manutenção preventiva agendada Reduz Disponibilidade (D)
Setup / Troca Troca de produto ou regulagem de máquina Reduz Disponibilidade (D)
Qualidade Retrabalho, série de defeitos Reduz Disponibilidade (D)

Motivos rápidos disponíveis: Falta de material · Manutenção corretiva · Setup/Troca · Falta de operador · Defeito de qualidade · Falta de energia. Clique no chip para preencher o campo automaticamente.

6.2 · Aba WIP — Produção em andamento

Mostra todos os apontamentos em andamento ou pausados neste momento. Use para saber a situação do chão de fábrica sem precisar descer até a produção.

IndicadorO que mede
Total de OPs ativasApontamentos com cronômetro rodando agora
OPs pausadasApontamentos parados aguardando resolução
Quantidade produzidaAcumulado do turno/período
Refugo do períodoPeças rejeitadas ou reprocessadas
Alerta automático

Se houver apontamentos em PARADA, um alerta amarelo aparece automaticamente no Dashboard principal.

6.3 · Aba OEE — Eficiência global do equipamento

O OEE mede a eficiência real da produção combinando disponibilidade e qualidade.

OEE = Disponibilidade (D) × Qualidade (Q)
ComponenteFórmulaO que afeta
Disponibilidade (D) Tempo produtivo ÷ Tempo total disponível Paradas, quebras, setups
Qualidade (Q) (Produzido − Refugo) ÷ Produzido Defeitos e retrabalho
Abaixo de 65% — requer ação imediata
65–84% — aceitável
≥ 85%

O gráfico de Pareto de paradas mostra quais motivos consomem mais tempo de máquina. Aja sobre os maiores primeiro — resolver o topo do Pareto gera o maior ganho de OEE.

  • Abrir o Dashboard e checar os alertas

  • Acessar Vendas × Estoque — identificar produtos críticos

  • Conferir fila do gargalo no TOC
  • Ajustar sequência no Preactor se houver mudança de prioridade
Mensal
  • Importar novos dados de Vendas e Estoque
  • Rodar Previsão de Demanda e Política de Estoques
  • Gerar Plano de Produção e emitir OPs no ERP
  • Atualizar análise TOC com nova demanda
  • Reagendar Preactor para o próximo mês

  • Revisar Calendário (turnos, feriados)
  • Atualizar Matriz de Set Up se houver novos produtos

Pontos de atenção e boas práticas

Não altere dados diretamente no banco

Todas as inserções e atualizações devem ser feitas pelas telas de importação do sistema. Alterações diretas no banco de dados quebram o histórico de atividades e podem corromper os cruzamentos.

Servidor automático no Mac

O servidor inicia automaticamente quando o Mac liga, via LaunchAgent. Se o sistema não responder após uma reinicialização, aguarde 1 minuto e tente novamente. Não é necessário abrir nenhum terminal.

Sempre faça backup antes de limpar dados

Use o botão ⬇ Backup no Dashboard antes de qualquer operação de limpeza (Limpar dados) ou reimportação de massa. O backup gera um arquivo JSON com todos os dados do sistema.

Respeite a sequência dos módulos

O sistema funciona em cadeia. Rodar a Política de Estoques sem ter a Previsão de Demanda calculada gera resultados incorretos. Sempre siga o fluxo: Configuração → Importação → S&OP → TOC → Preactor → MES.
