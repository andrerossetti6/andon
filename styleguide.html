Design System — Gestão Stoll

O manual vivo dos 4 sistemas (SIGS · APS · MES · N1Tech). Tudo que nascer novo usa o que está aqui — nada de reinventar botão, tabela ou cor.

Fonte: style.css (seção "Fundação Profissional") + ui-icons.js. Guia de uso do produto: Guia Integrado.

1 · Princípios
✓Cor é estado, não decoração. Verde = OK · âmbar = atenção · vermelho = estourado/ruptura · teal = ação/informação. Superfícies são neutras.
✓Ícone é SVG do sprite (icon('tear')) — traço 1.8, monocromático, herda a cor do texto. Nunca emoji na UI.
✓Número grande é Outfit + tabular (font-variant-numeric) — colunas alinham. Texto corrente é Inter 14px.
✓Falar como gente: títulos podem ser perguntas ("Onde a fábrica aperta?"); números vêm com tradução ("176% = faltam 2 pessoas").
✓Nada de estilo inline novo para o que já existe como componente: use .kpi .data-table .badge .meter .btn .sec-title .live-strip .prose-brief.
